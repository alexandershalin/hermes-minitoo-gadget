# Передача работы: MiniToo / Hermes (начни отсюда)

Этот каталог — для модели или человека, который продолжит работу после ночной сессии 2026-10-08/09. Все выводы о поведении самой колонки помечены как гипотезы: колонку на момент работы никто из агентов не трогал.

## Порядок чтения

1. `STATUS.md` — что сделано, что проверено, что нет. Самый важный файл.
2. `OPEN_TASKS.md` — что делать дальше, по приоритету.
3. `DECISIONS.md` — почему сделано именно так. Прочитать до того, как что-то менять.
4. `../SOLUTIONS.md` — разбор каждой проблемы из `HANDOFF.md` и таблица новых опций.
5. `../../HARDWARE_QUESTIONS.md` — вопросы, которые можно решить только на колонке.
6. `../research/` — сырые отчёты исследования (см. `../research/README.md`).
7. `../../HANDOFF.md` — исходный контекст от предыдущего ревьюера (на русском).

## Правила работы, которые задал владелец

- Пушить только в ветку `claude/inspiring-shannon-xl7a6h` (PR 7). В `main` не пушить, пока владелец не скажет.
- Не создавать PR без явной просьбы.
- Не запускать агентов и воркфлоу автоматически: квота сессии ограничена, и ночью она уже закончилась. Работать вручную, по шагам.
- **Не тестировать код на разных версиях Python.** Владелец прямо попросил этого не делать. Достаточно одного прогона `PYTHONPATH=src python -m pytest -q` и `ruff check .` на системном Python.
- Не выполнять команды с `sudo` и не просить у владельца пароль через бота. Всё, что требует root, — только инструкции в `scripts/system/`, ставит владелец сам.
- Не коммитить `config.json` (там токен), не класть в репозиторий прошивку и SDK (лицензия).
- Не писать в колонку ничего сверх того, что делает `origin/main`, без явного решения владельца. Все опции выключены по умолчанию.
- В сообщениях владельцу — по-русски, коротко, без лишних обещаний.

## Где что лежит

| Путь | Что это |
|---|---|
| `src/hermes_minitoo/` | Пакет: дисплей, транспорт, конфиг, проверка SCO (`linkstate.py`), хуки Gadget (`runtime.py`) |
| `scripts/minitoo-talk-key.py` | Сервис: Play/Pause → запись голоса (VAD, опциональный сокет, наблюдатель AT-команд) |
| `scripts/minitoo-autoaddr.py` | Сервис: следит за MAC колонки, переписывает `config.json` |
| `scripts/systemd/` | user-юниты |
| `scripts/system/` | root-файлы (modprobe, udev) — ставит владелец |
| `scripts/wireplumber/` | user-фрагменты WirePlumber, два из них выключены (`.disabled`) |
| `scripts/diag/` | диагностические скрипты, в основном только чтение |
| `tests/` | тесты, без железа (фейковые сокеты и часы) |
| `docs/AUDIT.md` | отчёт аудита (более ранний, статусы частично устарели — см. STATUS.md) |
| `docs/research/` | отчёты исследования |

## Что удалить / не трогать

- `.claude/worktrees/` — рабочие каталоги агентов. Они исключены из git через `.git/info/exclude`. Их ветки `worktree-wf_*` уже перенесены в основную ветку cherry-pick'ом; можно удалить (`git worktree remove --force …`), но не обязательно.
- Ветка `backup/before-integrate-*` и `backup/pr7-before-rebase` — страховка, удалять не нужно, пока PR не слит.
