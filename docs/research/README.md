# Отчёты исследования (копии)

Сырые отчёты, которые получены ночью проверяющими агентами. Каждое утверждение в них — с указанием файла и строки в исходниках (`BlueZ 5.85`, `PipeWire 1.6.2`, `WirePlumber 0.5.13`, `SDK 323e330`, SDK JieLi AC701N) или ссылки. Разделы «VERIFIER» — результат второй проверки; там часть утверждений исправлена («corrected»), и исправления важнее исходного текста.

- `hfp-button.md` — куда уходит Play/Pause во время SCO; dummy call; журнал WirePlumber; что отклоняет PipeWire.
- `display-link.md` — почему рвётся экран; таймауты; ворота; автосон USB; Intel 8087:0a2a.
- `divoom-protocol-alternatives.md` — варианты показа Listening; custom faces; BLE; служебные каналы.
- `mac-change.md` — почему адрес меняется; что такое `B1:21:81`; autoaddr.
- `firmware.md` — прошивка: чип BR28, режимы загрузки, барьеры, вывод.
- `code-audit.md` — дефекты кода по файлам, с воспроизведением.

Исходные JSON-результаты здесь не сохранены (сырой вывод воркфлоу).
